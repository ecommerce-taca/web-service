# Giỏ hàng (Cart)

## Trạng thái triển khai
- **UI Hoàn thành**: Trang `CartPage.jsx`.
  - Hiển thị danh sách sản phẩm trong giỏ (Group theo từng cửa hàng).
  - Có Checkbox chọn sản phẩm, tính tổng tiền.
  - Tăng giảm số lượng sản phẩm.
- **Tình trạng API**: UI đang dùng Mock data, cần ghép nối `cart.api.js` ở bước tiếp theo khi backend Cart hoàn thiện.
