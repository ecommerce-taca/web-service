# Thanh toán (Checkout & Payments)

## Trạng thái triển khai
- **UI Hoàn thành**: `CheckoutPage.jsx`.
  - Hiển thị danh sách địa chỉ nhận hàng (chọn từ Address Book).
  - Hiển thị tóm tắt giỏ hàng được chọn để thanh toán.
  - Lựa chọn phương thức vận chuyển và phương thức thanh toán (COD, Momo, VNPay).
- **Tình trạng API**: Chưa ghép API tạo đơn hàng (Create Order) và lấy link cổng thanh toán.
