# Tài khoản (Account / Users)

## Trạng thái triển khai
- **UI Hoàn thành**:
  - Khung `AccountLayout` với sidebar menu cá nhân hóa (Hồ sơ, Đơn hàng, Voucher, Yêu thích...).
  - `ProfilePage.jsx`: Sửa tên, ảnh đại diện, số điện thoại.
  - Address Book: Form Thêm/Sửa/Xóa địa chỉ giao hàng.
- **API Tích hợp**:
  - `GET /users/me` & `PUT /users/me`.
  - `GET/POST/PUT/DELETE /users/me/addresses`.
