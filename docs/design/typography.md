# Taca Ecommerce Typography (Tailwind CSS)

## Font Family
- **Font:** Plus Jakarta Sans
- **Tailwind Class:** `font-sans`

## Font Weights
- **Medium (500):** `font-medium`
- **Bold (700):** `font-bold`
- **ExtraBold (800):** `font-extrabold`

## Design Tokens & Sizes
| Penpot Name | Tailwind Class | Usage |
| ----------- | -------------- | ----- |
| Display 32 | `text-[32px] font-extrabold` | Major Hero / Banners |
| Heading 24 | `text-[24px] font-extrabold` | Section Headers, Logos |
| Heading 20 | `text-[20px] font-bold` | Titles |
| Body 16 | `text-[16px]` | Subtitles, Default Text |
| Body 14 | `text-[14px]` | Standard paragraphs |
| Label 12 | `text-[12px] font-bold` | Buttons, Inputs, Small Labels |
| Caption 10 | `text-[10px] font-medium` | Badges, Micro-copy |
